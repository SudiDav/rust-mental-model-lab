# Stack and Heap

A `String` value can keep a small descriptor on the stack while its variable-sized bytes live in a heap allocation.

<Concept>The stack stores function-local frames. The heap stores dynamic allocations whose size or lifetime needs more flexibility.</Concept>

<MentalModel>Follow the pointer: variable → pointer → address → bytes.</MentalModel>
