# Program Memory

A running program gets a conceptual address space containing code, static data, stack frames, and heap allocations.

<Concept>A process is an executing program with its own view of memory.</Concept>

<MentalModel>Picture a tall building: code and global data have fixed rooms, the stack grows through function workspaces, and the heap holds dynamic allocations.</MentalModel>
