# CPU and Memory

The CPU works with data through a hierarchy of increasingly large and increasingly distant storage layers.

<Concept>Registers are closest to the CPU. Cache, RAM, and storage trade speed for capacity and persistence.</Concept>

<MentalModel>Imagine a workbench, a nearby shelf, a room, and a warehouse. The farther away the item, the more work it takes to fetch.</MentalModel>
